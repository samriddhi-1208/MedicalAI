# 📁 MedGuardian AI — Folder Structure & Codebase Navigation Guide

This document provides a directory map and explanation of every major folder and file in the MedGuardian AI codebase.

---

## 1. Top-Level Directory Overview

```
MedicalAI/
├── .env.example              # Safe environment variable template for client
├── dist/                     # Vite production build artifacts (generated by npm run build)
├── docs/                     # Project technical documentation & interview guides
├── node_modules/             # Client npm dependencies
├── package.json              # Client dependencies, build, and dev scripts
├── README.md                 # Project root overview and quickstart guide
├── server/                   # Node.js + Express backend service
│   ├── .env.example          # Safe environment variable template for server
│   ├── package.json          # Server npm dependencies and startup scripts
│   ├── server.js             # Root backend entry point delegating to src/index.js
│   └── src/                  # Modular backend source code
└── src/                      # React 18 + Vite frontend source code
    ├── App.jsx               # Application root component wrapping context providers
    ├── main.jsx              # DOM entry point mounting root App
    ├── components/           # Reusable UI primitives and shared layout shells
    ├── constants/            # Client constants and REST API route registry
    ├── context/              # Central Context API state providers
    ├── hooks/                # Custom React hooks
    ├── pages/                # Route page components
    ├── routes/               # Central routing configuration and route guards
    ├── services/             # HTTP API abstraction layers
    ├── styles/               # CSS stylesheets and Tailwind design tokens
    └── utils/                # Helper utilities (formatters, translations, parsers)
```

## 2. Frontend Directory Breakdown (`src/`)

### `src/components/`
* **`components/shared/`**: Application-wide layout shells and route protectors.
  * `AppLayout.jsx`: Master layout wrapper managing collapsible desktop sidebar and reactive padding.
  * `Header.jsx`: Top navigation bar with language selector, theme toggle, and patient context.
  * `Sidebar.jsx`: Collapsible desktop navigation bar.
  * `MobileBottomNav.jsx`: Sticky 5-button bottom navigation bar for mobile viewports.
  * `Navbar.jsx` & `Footer.jsx`: Public marketing landing page navigation.
  * `ProtectedRoute.jsx`: Redirects unauthenticated users to `/login`.
  * `OnboardingRoute.jsx`: Redirects users with incomplete profiles to `/complete-profile`.
* **`components/ui/`**: Reusable design primitives and UI cards.
  * `Button.jsx`: Accessible button primitive with loading spinners and variants.
  * `Card.jsx`: Surface card container with subtle borders.
  * `Badge.jsx`: Accessible status badge (`normal`, `warning`, `critical`, `info`).
  * `Modal.jsx`: Accessible modal dialog with scroll locking.
  * `AIInsightCard.jsx`: Clinical insight summary cards.
  * `HealthMetricCard.jsx`: Metric display cards with trend arrows.
  * `MedicationCard.jsx`: Medication reminder card with time and dose tags.
  * `ReportCard.jsx`: Medical report card with analysis navigation.
  * `SkeletonLoader.jsx`: Shimmer loading state placeholders.
  * `NotificationDropdown.jsx`: Bell notification menu in header.

### `src/context/`
* `HealthDataContext.jsx`: Master health state store managing JWT tokens, profile state, active reports, medicines list, emergency contacts, and sync operations with backend API.
* `ThemeContext.jsx`: Theme manager toggling `.dark` class on root document and persisting state to `localStorage`.

### `src/hooks/`
* `useAuth.js`: Custom hook providing `{ user, token, login, logout, isAuthenticated }`.
* `useHealthData.js`: Custom hook exposing health context values and dispatcher functions.
* `useLanguage.js`: Custom hook exposing current language (`EN`/`HI`/`GU`) and translation function `t(key)`.

### `src/pages/`
* `DashboardPage.jsx`: Main health overview showing reports count, active meds, and recent activity.
* `ReportUploadPage.jsx`: Drag-and-drop report upload with duplicate checking and progress stepper.
* `AIAnalysisPage.jsx`: Structured AI clinical summaries, biomarker tables, and raw OCR inspection.
* `HealthTimelinePage.jsx`: Longitudinal biomarker charts and progress timelines.
* `MedicineReminderPage.jsx`: Medication schedule timeline, adherence metrics, and refill alerts.
* `EmergencySOSPage.jsx`: 1-Tap SOS trigger, 108 ambulance hotline, and live GPS status.
* `HospitalFinderPage.jsx`: Leaflet/OpenStreetMap proximity search for hospitals and clinics.
* `ProfilePage.jsx`: Comprehensive medical baseline and physical measurements form.
* `OnboardingPage.jsx`: Mandatory 2-step profile onboarding wizard.
* `LoginPage.jsx` & `SignupPage.jsx`: Authentication forms with password complexity validation.
* `LandingPage.jsx`: Public marketing landing page.
* `SettingsPage.jsx`: Application preferences, language, notifications, and data management.
* `ForgotPasswordPage.jsx`: Password recovery email flow.
* `NotFoundPage.jsx`: 404 fallback page.

### `src/routes/`
* `AppRoutes.jsx`: Central routing tree defining public, auth, onboarding, protected `/app/*`, and fallback routes.

### `src/services/`
* `api.js`: Standardized Fetch client with automatic Bearer token injection and error handling.
* `authService.js`: Authentication endpoints wrapper (`login`, `signup`, `getProfile`, `updateProfile`).
* `reportService.js`: Report upload and history fetching wrapper.
* `medicineService.js`: Medication CRUD operations wrapper.
* `emergencyService.js`: SOS trigger and emergency contacts wrapper.
* `hospitalService.js`: Nearby hospital search wrapper.

### `src/utils/`
* `formatters.js`: Formatting helpers for dates, numbers, and display names.
* `reportParser.js`: Client-side OCR parsing, universal clinical regex extractor, and summary builders.
* `storage.js`: LocalStorage wrappers for tokens and user profiles.
* `translations.js`: Trilingual dictionary for English, Hindi, and Gujarati strings.

## 3. Backend Directory Breakdown (`server/`)

### `server/`
* `server.js`: Root entry point delegating execution to `./src/index.js`.
* `package.json`: Server dependencies (`express`, `mongoose`, `cors`, `multer`, `pdf-parse`, `nodemailer`, `bcryptjs`, `jsonwebtoken`).

### `server/src/`
* `index.js`: HTTP server entry point establishing MongoDB Atlas connection before binding port.
* `app.js`: Express application setup, CORS configuration, JSON body parsing, upload route mounting, and global error handling.
* **`src/config/`**:
  * `db.js`: Mongoose connection manager with retry logic.
* **`src/constants/`**:
  * `index.js`: System constants (`HTTP_STATUS`, payload limits).
* **`src/controllers/`**:
  * `authController.js`: Registration, login, JWT issuance, profile retrieval, and updates.
  * `reportsController.js`: Report ingestion, duplicate checking, and history retrieval.
  * `medicinesController.js`: Medication schedule CRUD and dose logging.
  * `sosController.js`: Emergency event triggering, contact management, and alert dispatch.
  * `hospitalsController.js`: OpenStreetMap/Overpass proximity querying.
  * `vitalsController.js`: Biomarker history aggregation.
* **`src/middlewares/`**:
  * `authMiddleware.js`: JWT token verification and attaching authenticated user to `req.user`.
  * `errorHandler.js`: Global error formatting middleware preventing stack trace leakage.
  * `uploadMiddleware.js`: Multer memory storage configuration with 15MB file limit.
* **`src/models/`**:
  * `User.js`: User credentials, demographics, and physical baseline schema.
  * `Report.js`: Medical report metadata, file hashes, and raw OCR text.
  * `ReportSummary.js`: Clinical AI summaries and recommended action items.
  * `ReportValue.js`: Individual biomarker test results and reference ranges.
  * `Medicine.js`: Medication scheduling and dosing instructions.
  * `MedicineLog.js`: Timestamped history of taken doses.
  * `SOSEvent.js`: Emergency alert triggers with GPS coordinates.
  * `EmergencyContact.js`: Trusted emergency contacts per user.
* **`src/routes/`**:
  * `authRoutes.js`, `reportsRoutes.js`, `medicinesRoutes.js`, `sosRoutes.js`, `hospitalsRoutes.js`, `vitalsRoutes.js`.
* **`src/services/`**:
  * `aiService.js`: Google Gemini API client and Universal Clinical Extractor fallback.
  * `ocrService.js`: PDF and image text extraction engine (`pdf-parse`).
  * `emailService.js`: Nodemailer transporter for email notifications.
  * `sosAlertService.js`: Emergency alert payload formatting and dispatch.
* **`src/utils/`**:
  * `generateToken.js`: Signed JWT generator utility.
* **`src/validators/`**:
  * `authValidator.js` & `reportValidator.js`: Payload schema validation rules.
